# BaseShift

A beautifully designed, real-time number base converter that visually breaks down the mathematical steps of conversion.

## How to enable GitHub Pages

1. Push this code to a new repository on GitHub (e.g., `baseshift`).
2. Go to your repository **Settings**.
3. In the left sidebar, click on **Pages**.
4. Under the **Build and deployment** section, select **Deploy from a branch**.
5. Set the branch to `main` (or `master`) and the folder to `/ (root)`.
6. Click **Save**.
7. Wait a minute or two, and your site will be published at your `github.io` domain!
